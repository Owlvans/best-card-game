An original card duel built for the [make.fun](https://make.fun/bounty/best-card-game-20261122-1826) best-card-game bounty.

Both heroes start at 20 life. Energy grows each turn. Play creatures and spells from three houses — Ember (red, triangle), Tide (blue, circle), and Thorn (green, diamond) — use Guard and Rush, trade wisely against a readable AI opponent, and bring the enemy hero to zero.

Play by opening `game/index.html` in a desktop browser. No build step, no network. Mouse and keyboard (1–5 to play, Enter to end turn).

Screenshots: `01-table.png` is the cover (seeded mid-game table), followed by title, win, and loss screens.
